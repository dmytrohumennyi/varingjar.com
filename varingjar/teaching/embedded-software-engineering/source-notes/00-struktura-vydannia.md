## Update protocol for every new upload

1. Preserve the raw transcript unchanged.
2. Append a new dated session; never regenerate earlier sessions.
3. Correct obvious transcription mistakes in the new session.
4. Separate lecturer-derived content from editor/web additions.
5. Verify factual corrections and recommended links.
6. Add questions, comments, tables/diagrams where they improve learning value.
7. Add a forecast for the next 1–2 sessions, clearly marked as a forecast.
8. Run site validation and cross-viewport checks.
9. Regenerate the site navigator data (assets/js/site-tree.js and site-search-<lang>.js) so the new session appears in the site map and search.
10. Keep the three language versions in step: EN, UK and DE pages, course index, teaching overview, sitemap.xml and assets/data/course-embedded-software-engineering.json.

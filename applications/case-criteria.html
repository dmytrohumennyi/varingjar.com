Selection rule

A useful Væringjar II case has four properties.

01

Irreversible change

The object is physically or structurally different after the failure.

02

Residual resources

Some control authority remains; the system is not simply dead.

03

Mission value

There is value in preserving some function instead of immediately stopping.

04

Verifiable boundary

Continued operation can be tested against stability, timing and safety constraints.

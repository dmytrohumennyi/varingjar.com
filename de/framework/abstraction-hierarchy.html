Die Vier-Ebenen-Hierarchie: Ressource → Dienst → Funktion → Mission.

Im Kern steht die konstruktive Kopplung zwischen Ressourcen, Diensten, Funktionen und Mission. Dadurch wird Überlebensfähigkeit zur berechenbaren Größe S(t).

Vier Abstraktionsebenen

Das superkritische System wird als Hierarchie dargestellt: Die Mission wird über Funktionen realisiert, Funktionen über Dienste und Dienste über Ressourcen.

H = ⟨ M, F, Sv, Rs ⟩
Rs = {r1 … rn}, Sv = {s1 … sq}, F = {F1 … Fm}

Abbildungen zwischen Ebenen

Matrizen V, B und W

Die Abbildung „Dienst → Ressource“ wird durch V beschrieben, die Abbildung „Funktion → Dienst“ durch B. Ihr Produkt W = B·V liefert die Einflussmatrix von Ressourcen auf Funktionen.

W = B · V
wji = Σk bjk · vki

Das ist wichtig, weil die Einflussmatrix nicht nur intuitiv gesetzt, sondern aus zwei physikalisch interpretierbaren Abbildungen abgeleitet wird.

Die Formel der ÜberlebensfähigkeitAbschnitt öffnen
Von der Ressource zur Mission

Die Formel der Überlebensfähigkeit

Sobald für jede Ressource der Betriebsfähigkeitskoeffizient ρi(t) vorliegt, steigt das Modell zur Funktions- und Missionsebene auf.

S(t) = Σ αj · δj(cfg) · φj(t, cfg)
αj — Missionspriorität, δj — Aktivität, φj — Integrität.

Das Framework beantwortet damit nicht nur die vage Frage „funktioniert das System noch?“, sondern die quantitative: welcher Anteil der Missionsfähigkeit aktuell noch erhalten ist.

Auch Modellgültigkeit ist eine Ressource.

Das Framework führt epistemische Ressourcen ein: Modelle, Schätzer, Identifikatoren und gelernte Politiken, deren Gültigkeit genauso überwacht werden muss wie der physische Zustand.

Neuer Ressourcentyp

Wenn nicht der Sensor, sondern das Wissen degradiert

Das System kann nicht nur ein physisches Element verlieren, sondern auch die Gültigkeit seines Wissens: ein veraltetes Modell, einen falschen Schätzer oder eine beschädigte gelernte Politik.

Das ist gefährlich, weil die Hardware gesund erscheinen kann, während Entscheidungen bereits auf einer falschen Grundlage beruhen.

Quelle in der Dissertation: §§2.7.1–2.7.8

Gültigkeitskoeffizient

Wie eine epistemische Ressource bewertet wird

Für eine epistemische Ressource wird ein Gültigkeitskoeffizient eingeführt, der mit Vorhersagefehler und Zeit seit der letzten Validierung abnimmt.

ρm(t) = exp( − κe·em(t) − κτ·Δτm )

Diese Gültigkeit unterliegt denselben Supervisor-Entscheidungen: Ein Modell kann deaktiviert, ersetzt, revalidiert oder durch eine andere Konfiguration kompensiert werden.

Quelle in der Dissertation: §§2.7.1–2.7.8

Auch die Wiederherstellung von Gültigkeit ist eine Aktion

Mit epistemischen Ressourcen umfasst Rekonfiguration nicht nur das Umschalten von Hardware oder Software, sondern auch Wissenswiederherstellung: Rekalibrierung, Re-Identifikation, Aktivierung eines Reservemodells oder Rückfall auf ein einfacheres, aber gültiges Regelgesetz.

Quelle in der Dissertation: §§2.7.1–2.7.8
